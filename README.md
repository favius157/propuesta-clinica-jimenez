# Propuesta Clínica Jiménez · UNISOFT

Configurador de la propuesta modular. El cliente elige módulos, alojamiento y forma de pago, y envía su selección por correo.

- Publicación: GitHub Pages (rama `main`, carpeta raíz).
- Envío de correo: FormSubmit (https://formsubmit.co). La selección llega a la cuenta configurada y el cliente recibe una copia.
- Un solo envío: después de enviar, la página queda bloqueada en ese navegador y muestra la selección enviada.

## Activación del correo (una sola vez)
El primer envío dispara un correo de FormSubmit pidiendo confirmar la dirección. Hay que abrirlo y pulsar "Activate Form" antes de compartir el enlace con el cliente.
